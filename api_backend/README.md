# MailMind Sandbox API\n\nFastAPI public demo API. Accepts sample email text, classifies it, tries Gemini draft generation and falls back to local reply rules. No email inbox access, storage, or sending. Includes a small in-memory rate limit.\n\nRender settings: Root Directory `api_backend`; Build Command `pip install -r requirements.txt`; Start Command `uvicorn main:app --host 0.0.0.0 --port $PORT`. Add `GEMINI_API_KEY` and optional `GEMINI_MODEL` as environment variables.\n
