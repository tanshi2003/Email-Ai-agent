03 / Under the hood

Small modules.
Clear responsibilities.

The repository keeps the email reader, sender and reply-generation logic separate, making it easier to extend and test each part.

MODULE / 01

email_reader.py

Connects through IMAP SSL, retrieves unread messages and extracts email content with charset handling.

MODULE / 02

ai_logic.py

Supports optional Gemini-generated drafts, with a deterministic keyword-based fallback.

MODULE / 03

email_sender.py

Formats a reply and sends it through Gmail SMTP over SSL in the live automation workflow.
